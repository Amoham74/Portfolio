# Professional Portfolio Website

A modern, responsive portfolio website designed to showcase your professional experience, skills, and projects. Built with HTML, CSS, and JavaScript, this portfolio features a clean design with smooth animations and excellent user experience.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Interactive Elements**: Hover effects, scroll animations, and dynamic content
- **Contact Form**: Functional contact form with validation
- **Skills Visualization**: Animated skill bars and tags
- **Project Showcase**: Beautiful project cards with links and descriptions
- **Timeline Experience**: Visual timeline for work experience
- **Accessibility**: Keyboard navigation and screen reader friendly

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **About**: Personal introduction with key statistics
3. **Experience**: Timeline-based work history
4. **Projects**: Portfolio of featured projects
5. **Skills**: Technical and soft skills with visual indicators
6. **Contact**: Contact information and message form

## Customization Guide

### Personal Information
Update the following in `index.html`:

- **Name**: Replace "Your Name" throughout the document
- **Title**: Update "Professional Title / Role" in the hero section
- **Description**: Customize the hero description and about section
- **Contact Info**: Update email, phone, and location
- **Social Links**: Add your LinkedIn, GitHub, and other social media profiles

### Experience Section
Replace the timeline items with your actual work experience:
- Job titles
- Company names
- Dates
- Key achievements and responsibilities

### Projects Section
Update the project cards with your actual projects:
- Project names and descriptions
- Technologies used (as tags)
- Links to live demos and source code
- Project images (replace placeholder icons)

### Skills Section
Customize the skills to match your expertise:
- Technical skills with proficiency levels
- Soft skills as tags
- Adjust skill bar percentages

### Styling
The website uses a modern color scheme that can be customized in `styles.css`:
- Primary color: `#2563eb` (blue)
- Secondary color: `#fbbf24` (yellow)
- Background gradients and other colors

## Deployment

This portfolio is configured for deployment on Render.com. The `render.yaml` file in the parent directory contains the deployment configuration.

### Local Development
1. Clone or download the project
2. Open `index.html` in your web browser
3. Customize the content as needed
4. Test on different devices and screen sizes

### Render.com Deployment
1. Push your customized portfolio to a Git repository
2. Connect your repository to Render.com
3. The site will automatically deploy using the configuration in `render.yaml`
